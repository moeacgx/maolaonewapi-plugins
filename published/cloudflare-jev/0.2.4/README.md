# Cloudflare Jev 任务插件 0.2.4

## 目标与合同

保留使用错误日志，同时使用主程序通用性能过滤钩子，避免错误客户端入口被作为模型失败样本。
新增 requiredCapabilities: ["task-performance-filter@1"] 和 shouldRecordPerformanceFailure(ctx, failure)。
只有上下文具有本插件身份、已声明模型、HTTP方法和绝对路径时才判断；信息缺失或不是本插件时沿用统计。

合法客户端提交入口为 meta.routes 中的 POST /v1/systemone 和宿主通用
POST /v1/task/plugins/cloudflare-jev。比较完整方法与路径，不匹配前缀、不接受资源子路径。
合法路径上的 HTTP 400/401/403/404/429/5xx、网络失败、解析失败和业务失败一律交给宿主原统计，
不凭状态码或错误码猜测为用户误用。实际最终是否计入仍受宿主策略、管理员过滤和取消规则约束。

错误路径的上下文返回 false，仅排除性能失败，不关闭日志、不改返回结果、计费或退款。
方法和路径由宿主提供；不使用客户端正文、请求头或 Cloudflare 私有 /ai/run 路径作判断。
截图中 /v1/responses 等请求在现有宿主的分发阶段终止，插件不会执行，本来就不会产生性能样本；
本版本的钩子是插件明确声明合法入口的补充约束，不声称它接管了错误路由。

## 兼容和升级

- 必须先升级至包含 NewAPI-Mao PR #276（提交 ca5d5ebbd8d6658704ffdf7321d88cddc74165d2）
  的宿主，再安装并激活本版本。API version 1 不代表支持新能力。
- .337 及更早已发布宿主不支持 task-performance-filter@1，安装本版本会被能力校验拒绝；
  这些宿主继续使用 0.2.3。不要删除 requiredCapabilities 绕过兼容门禁。
- 0.2.3 及历史源码/路径/hash 保持不变。回退激活旧版不改渠道和定价，不清理历史日志。
- 模型、Cloudflare地址认证、Completed响应解析及输入/输出token行为沿用
  [0.2.3](../0.2.3/README.md)；支持 typesafe/jev 和经映射的 Typesafe-jev。
